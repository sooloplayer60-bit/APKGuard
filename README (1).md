# APK Guard для Android

Настоящее приложение: проверяет установленные приложения и APK-файлы, а в фоне
проверяет каждое новое приложение сразу после установки.

## Как получить APK-файл (без компьютера, только с телефона)

1. Зайдите на github.com и создайте бесплатный аккаунт.
2. Нажмите «+» → «New repository», назовите, например, `apkguard`, нажмите «Create repository».
3. Нажмите «creating a new file» (или Add file → Create new file).
4. В поле имени введите: `.github/workflows/build.yml`
   (слэши автоматически создадут папки).
5. Откройте присланный файл `build.yml`, выделите весь текст, скопируйте и вставьте в большое поле.
6. Внизу нажмите «Commit changes».
7. Откройте вкладку «Actions». Сборка запустится сама (3–6 минут), появится зелёная галочка.
8. Нажмите на завершённую сборку, внизу в разделе «Artifacts» скачайте `APK-Guard`.
9. Распакуйте архив, откройте `app-debug.apk` и установите (разрешите установку из этого источника).

Если на шаге 7 появился красный крестик: откройте сборку, скопируйте последние строки
красного лога и пришлите мне, я исправлю.

## Если у вас есть компьютер

Распакуйте zip-проект, откройте его в Android Studio и нажмите Build → Build APK.
Или загрузите папку проекта в репозиторий GitHub: workflow уже лежит в `.github/workflows/build.yml`.

## Что внутри

- `Scanner.java`: проверка по шести уровням (хэши, структура, подпись, разрешения, код, скрытые файлы).
- `GuardService.java`: фоновая защита, уведомления об угрозах.
- `MainActivity.java`: экран приложения.
- Важно: Google Play Protect может показать предупреждение «неизвестный разработчик», потому что
  приложение подписано отладочным ключом. Это нормально для приложений вне Google Play.

## Настройка на телефоне

Чтобы защита не отключалась системой: Настройки → Приложения → APK Guard → Батарея → «Без ограничений».

## Двойная защита от APK (новое)

1. **Ступень 1, скачивание.** Когда браузер или менеджер загрузок скачал APK, показывается экран
   с проверкой файла и выбором: «Не устанавливать (удалить файл)» или «Он безопасный, продолжить».
2. **Ступень 2, запуск.** Приложение, установленное не из магазина, при первом запуске закрывается
   предупреждением: «Закрыть приложение» или «Открыть, я доверяю».

Для работы нужны два разрешения (кнопки на главном экране): доступ к статистике использования
и показ поверх других приложений. Ограничение: ступень 1 срабатывает на загрузки через системный
менеджер загрузок; если браузер скачивает файл сам, предупреждение появится при установке-запуске (ступень 2).
Приложения из Google Play и системные больше не получают «100/100» только из-за разрешений.

## Сборка Android и Windows из GitHub Actions

В проект добавлен workflow `.github/workflows/build-all.yml`. Загрузите содержимое этой папки в GitHub-репозиторий, откройте вкладку **Actions** и запустите **Build APK Guard for Android and Windows** (или дождитесь автоматического запуска после push в `main`/`master`). После успешной сборки скачайте два артефакта:

- `APK-Guard-Android` — APK для Android;
- `APK-Guard-Windows` — ZIP-папка Windows-приложения. Распакуйте её и запустите `APKGuard\APKGuard.exe`, сохраняя рядом остальные файлы папки.

Windows-версия использует общий `Scanner.java` и проверяет выбранный APK локально. Она не является полноценным антивирусом: это эвристический статический анализ, поэтому результат не гарантирует безопасность файла.


## Быстрая сборка обеих версий

1. Создайте репозиторий на GitHub и загрузите в него **содержимое этого архива** (файлы `settings.gradle`, `app/`, `desktop/`, `.github/` должны лежать в корне репозитория).
2. Откройте вкладку **Actions** и выберите workflow **Build APK Guard for Android and Windows**.
3. Нажмите **Run workflow** и дождитесь завершения двух задач.
4. Внизу страницы запуска скачайте артефакты `APK-Guard-Android` и `APK-Guard-Windows`.

Сборка выполняется на серверах GitHub: Android APK собирается на Linux runner, Windows EXE — на Windows runner. Из этой среды нельзя выпустить подписанный Android APK и нативный Windows EXE, поэтому архив содержит готовую конфигурацию автоматической сборки, а не уже собранные бинарные файлы.
