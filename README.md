# APK Guard для Windows

Windows-версия использует тот же Java-сканер `Scanner.java`, что и Android-приложение. Она проверяет выбранный APK локально: SHA-256, ZIP-структуру, наличие подписи, разрешения из манифеста, подозрительные строки в DEX и вложенные файлы.

## Сборка EXE на Windows

1. Установите JDK 17 или новее и убедитесь, что команды `java`, `javac`, `jar` и `jpackage` доступны в PATH.
2. Запустите `build-windows.bat`.
3. Готовое приложение появится в `dist\APKGuard\APKGuard.exe`.
4. Переносите всю папку `APKGuard`, а не один EXE: внутри находится Java runtime.

Для автоматической сборки обеих версий откройте GitHub Actions и запустите workflow **Build APK Guard for Android and Windows**. Готовые APK и ZIP с Windows-приложением будут в Artifacts.

## Ограничения

Это статический эвристический анализатор, а не полноценный антивирус. Он не запускает APK и не проверяет поведение приложения в песочнице, не сверяет файлы с облачной базой угроз. Отсутствие находок не означает, что APK гарантированно безопасен.
